# Anchal & Divyank wedding invitation
Run `python -m http.server 8000` in this folder and open http://localhost:8000. No npm required. Edit wedding-config.js for names, dates, events, venue and contacts. The original compiled React/Motion bundle is adapted, not original JSX. Family text is in FamilyInvitation in the bundle. Hindi spellings are transliterations; verify with family. The card does not specify venues for December 10 or Vidai; these are marked unconfirmed. RSVP WhatsApp uses the first printed contact; confirm it is WhatsApp-enabled and authorized before sharing. Music disabled until a licensed audio file is supplied; set music.file and music.start in config. Old social preview omitted because it names the other couple; add a new image and absolute OG URL after deployment. Google fonts/maps need internet. Guest links: ?to=Guest%20Name. Obtain permission to reuse original code/assets. Browser rendering not verified.

Music: supplied Din Shagna Da instrumental MP3, loops, fades in on playback. Audio is local to the project. Browser playback requires user interaction.
